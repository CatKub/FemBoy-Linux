# FemBoy-Linux

### An independent Arch Linux-based Linux distribution

FemBoy-Linux is a custom Linux distribution based on
[Arch Linux](https://archlinux.org/).

The project aims to provide a customizable, lightweight,
and community-driven Arch-based Linux experience.

You can either **download the pre-built ISO** or **build
FemBoy-Linux yourself from the source code**.

# 🏹 Based on Arch Linux

FemBoy-Linux is based on **Arch Linux**.

It uses Arch Linux as the foundation and adds its own:

- Package selection
- Configuration
- Archiso profile
- System customization
- Scripts
- Documentation
- Project-specific changes

FemBoy-Linux is an **independent project**.

It is **not an official Arch Linux distribution** and is
not affiliated with or endorsed by the Arch Linux project.

Learn more about Arch Linux:

https://archlinux.org/

# 📦 Requirements

To build FemBoy-Linux yourself, you will need:

- A working Linux system
- x86_64 architecture
- Internet connection
- Git
- Archiso
- Enough disk space for the build

Arch Linux is recommended as the build environment.
